# HY-LITE 单词学习网站 —— 说明书

> 给「未来的你」或「任何接手改这个网站的人」看。就算当初做它的那个 AI 对话没了，照这个也能接着改。

## 这是什么

一个单词背诵网页 App（百词斩风格），HY-LITE 环亚国际教育用。
纯静态、单文件、离线可用，双击 `index.html` 就能在浏览器里跑，不需要联网、不需要服务器。

内含 3 本词书，首页可切换：
- **必会 3000**（59单元3000词）—— 每天 50 词
- **B1**（13单元684词）—— 每天 1 个单元
- **B1+**（13单元627词）—— 每天 1 个单元

## 发给别人 / 部署，用哪个文件？

就用 **`index.html`**（vocabulary 文件夹里、以及上一级 HY 文件夹里都有一份，内容一样）。这一个文件包含全部内容和词库。

## 改单词 / 加词怎么办？

**最简单：新开一个 Claude 对话**，把 vocabulary 文件夹发给它，说「帮我改 HY 文件夹这个单词网站，我要改 XX」。

**自己改（需要一点电脑基础）：**
词库在 `src\` 里两个文件：
- `units-data.js` —— 必会3000 的词（变量 `BOOK3000`）
- `books-extra.js` —— B1 / B1+ 的词（变量 `B1_UNITS` / `B1P_UNITS`）

格式：每个词是 `["单词","中文释义","音标"]`，按单元分组：
`{id:"U1", name:"Unit 1", words:[ ["apple","苹果","ˈæp(ə)l"], ... ]}`

改完要重新打包成 `index.html`：在 vocabulary 文件夹里，按住 Shift 右键 →「在此处打开 PowerShell」→ 输入：
```
powershell -ExecutionPolicy Bypass -File build.ps1
```
回车，就生成新的 `index.html`，发出去/传服务器即可（学生进度不受影响）。

## 文件夹里都是啥

```
vocabulary\
├── index.html          ← 打包好的成品（能直接用）
├── build.ps1           ← 改完源码后重新打包的脚本
├── 这是什么-怎么改.md    ← 你正在看的这份
└── src\                ← 源码（改这里）
    ├── units-data.js   ← 必会3000 词库
    ├── books-extra.js  ← B1 / B1+ 词库
    ├── bc-core.js      ← 核心（记忆算法、存储、多词书）
    ├── bc-session.js   ← 答题、速刷、连连看
    ├── bc-views.js     ← 各页面显示
    ├── bc.css          ← 样式配色
    ├── bc-body.html    ← 页面骨架
    └── shell.html      ← 打包模板
```

## 学生进度存哪？

存在每个人自己手机/电脑的浏览器里（localStorage），互不影响，不上传。
换设备：App 里「我的 → 导出进度备份」导出，新设备「导入进度」恢复。
⚠️ 网址（域名/IP）一旦定了别再换，否则学生进度会丢。
